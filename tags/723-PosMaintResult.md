# FIX 4.4 : PosMaintResult <723> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Result of [Position Maintenance Request <AL>](https://www.onixs.biz/fix-dictionary/4.4/msgType_AL_6576.html).

Valid values:

0 = Successful completion - no warnings or errors

1 = Rejected

99 = Other

4000+ Reserved and available for bi-laterally agreed upon user-defined values
