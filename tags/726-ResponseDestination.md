# FIX 4.4 : ResponseDestination <726> field

**Type:** [String](https://www.onixs.biz/fix-dictionary/4.4/index.html#String)

## Description

URI (Uniform Resource Identifier) for details) or other pre-arranged value. Used in conjunction with [ResponseTransportType <725>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_725.html) value of Out-of-Band to identify the out-of-band destination.

See [Appendix 6-B: FIX Fields Based Upon Other Standards](https://www.onixs.biz/fix-dictionary/4.4/app_6_b.html)
