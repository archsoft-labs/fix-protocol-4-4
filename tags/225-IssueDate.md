# FIX 4.4 : IssueDate <225> field

**Type:** [LocalMktDate](https://www.onixs.biz/fix-dictionary/4.4/index.html#LocalMktDate)

## Description

The date on which a bond or stock offering is issued. It may or may not be the same as the effective date ([DatedDate <873>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_873.html)) or the date on which interest begins to accrue ([InterestAccrualDate <874>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_874.html))

(Note tag # was reserved in FIX 4.1, added in FIX 4.3)

(prior to FIX 4.4 field was of type UTCDate)
