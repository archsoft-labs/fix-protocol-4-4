# FIX 4.4 : IOIQty <27> field

**Type:** [String](https://www.onixs.biz/fix-dictionary/4.4/index.html#String)

## Description

Quantity (e.g. number of shares) in numeric form or relative size.

Valid values:

0 - 1000000000

S = Small

M = Medium

L = Large
