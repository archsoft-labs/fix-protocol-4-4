# FIX 4.4 : SecurityListRequestType <559> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Identifies the type/criteria of [Security List Request <x>](https://www.onixs.biz/fix-dictionary/4.4/msgType_x_120.html)

Valid values:

0 = [Symbol <55>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_55.html)

1 = [SecurityType <167>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_167.html) and/or [CFICode <461>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_461.html)

2 = [Product <460>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_460.html)

3 = [TradingSessionID <336>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_336.html)

4 = All Securities
