# FIX 4.4 : LastFragment <893> field

**Type:** [Boolean](https://www.onixs.biz/fix-dictionary/4.4/index.html#Boolean)

## Description

Indicates whether this message is the last in a sequence of messages for those messages that support fragmentation, such as [Allocation Instruction <J>](https://www.onixs.biz/fix-dictionary/4.4/msgType_J_74.html), [Mass Quote <i>](https://www.onixs.biz/fix-dictionary/4.4/msgType_i_105.html), [Security List <y>](https://www.onixs.biz/fix-dictionary/4.4/msgType_y_121.html), [Derivative Security List <AA>](https://www.onixs.biz/fix-dictionary/4.4/msgType_AA_6565.html)

Valid values:

Y = Last message

N = Not last message
