# FIX 4.4 : PosMaintStatus <722> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Status of [Position Maintenance Request <AL>](https://www.onixs.biz/fix-dictionary/4.4/msgType_AL_6576.html)

Valid values:

0 = Accepted

1 = Accepted with Warnings

2 = Rejected

3 = Completed

4 = Completed with Warnings
