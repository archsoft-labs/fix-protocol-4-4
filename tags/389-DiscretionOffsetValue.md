# FIX 4.4 : DiscretionOffsetValue <389> field

**Type:** [float](https://www.onixs.biz/fix-dictionary/4.4/index.html#float)

## Description

Amount (signed) added to the "related to" price specified via [DiscretionInst <388>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_388.html), in the context of [DiscretionOffsetType <842>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_842.html)

(Prior to FIX 4.4 this field was of type [PriceOffset](https://www.onixs.biz/fix-dictionary/4.4/index.html#PriceOffset) and named DiscretionOffset)
