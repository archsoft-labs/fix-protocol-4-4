# FIX 4.4 : OddLot <575> field

**Type:** [Boolean](https://www.onixs.biz/fix-dictionary/4.4/index.html#Boolean)

## Description

This trade is to be treated as an odd lot

Values:

Y = treat as odd lot

N = treat as round lot

If this field is not specified, the default will be "N"
