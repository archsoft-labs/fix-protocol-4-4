# FIX 4.4 : AllocLinkID <196> field

**Type:** [String](https://www.onixs.biz/fix-dictionary/4.4/index.html#String)

## Description

Can be used to link two different Allocation messages (each with unique [AllocID <70>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_70.html) together, i.e. for F/X "Netting" or "Swaps". Should be unique.
