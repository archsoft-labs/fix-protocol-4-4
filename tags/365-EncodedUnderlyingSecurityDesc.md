# FIX 4.4 : EncodedUnderlyingSecurityDesc <365> field

**Type:** [data](https://www.onixs.biz/fix-dictionary/4.4/index.html#data)

## Description

Encoded (non-ASCII characters) representation of the [UnderlyingSecurityDesc <307>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_307.html) field in the encoded format specified via the [MessageEncoding <347>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_347.html) field. If used, the ASCII (English) representation should also be specified in the UnderlyingSecurityeDesc field.
