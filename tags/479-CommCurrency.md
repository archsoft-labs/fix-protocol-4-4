# FIX 4.4 : CommCurrency <479> field

**Type:** [Currency](https://www.onixs.biz/fix-dictionary/4.4/index.html#Currency)

## Description

Specifies currency to be use for [Commission <12>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_12.html) if the Commission currency is different from the Deal Currency.

See [Appendix 6-A: Valid Currency Codes](https://www.onixs.biz/fix-dictionary/4.4/app_6_a.html).
