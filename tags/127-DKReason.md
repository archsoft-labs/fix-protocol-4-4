# FIX 4.4 : DKReason <127> field

**Type:** [char](https://www.onixs.biz/fix-dictionary/4.4/index.html#char)

## Description

Reason for execution rejection.

Valid values:

A = Unknown symbol

B = Wrong side

C = Quantity exceeds order

D = No matching order

E = [Price <44>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_44.html) exceeds limit

F = Calculation difference

Z = Other
