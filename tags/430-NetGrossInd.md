# FIX 4.4 : NetGrossInd <430> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Code to represent whether value is net (inclusive of tax) or gross.

Valid values:

1 = Net

2 = Gross
