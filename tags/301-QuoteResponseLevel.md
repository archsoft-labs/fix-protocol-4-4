# FIX 4.4 : QuoteResponseLevel <301> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Level of Response requested from receiver of Quote messages.

Valid values:

0 = No Acknowledgement (Default)

1 = Acknowledge only negative or erroneous quotes

2 = Acknowledge each Quote messages
