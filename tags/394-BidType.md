# FIX 4.4 : BidType <394> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Code to identify the type of [Bid Request <k>](https://www.onixs.biz/fix-dictionary/4.4/msgType_k_107.html).

Valid values:

1 = "Non Disclosed" Style (e.g. US/European)

2 = "Disclosed" Style (e.g. Japanese)

3 = No Bidding Process
