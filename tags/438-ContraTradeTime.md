# FIX 4.4 : ContraTradeTime <438> field

**Type:** [UTCTimestamp](https://www.onixs.biz/fix-dictionary/4.4/index.html#UTCTimestamp)

## Description

Identifes the time of the trade with the [ContraBroker <375>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_375.html). Always expressed in UTC (Universal Time Coordinated, also known as "GMT")
