# FIX 4.4 : InvestorCountryOfResidence <475> field

**Type:** [Country](https://www.onixs.biz/fix-dictionary/4.4/index.html#Country)

## Description

The ISO 3166 Country code (2 character) identifying which country the beneficial investor is resident for tax purposes.

(e.g [https://en.wikipedia.org/wiki/ISO_3166-1](https://en.wikipedia.org/wiki/ISO_3166-1))
