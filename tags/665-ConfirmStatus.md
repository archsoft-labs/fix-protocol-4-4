# FIX 4.4 : ConfirmStatus <665> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Identifies the status of the [Confirmation <AK>](https://www.onixs.biz/fix-dictionary/4.4/msgType_AK_6575.html).

Valid values:

1 = Received

2 = Mismatched account

3 = Missing settlement instructions

4 = Confirmed

5 = Request rejected
