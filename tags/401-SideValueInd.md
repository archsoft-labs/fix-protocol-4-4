# FIX 4.4 : SideValueInd <401> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Code to identify which "SideValue" the value refers to. [SideValue1 <396>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_396.html) and [SideValue2 <397>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_397.html) are used as opposed to Buy or Sell so that the basket can be quoted either way as Buy or Sell.

Valid values:

1 = [SideValue1 <396>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_396.html)

2 = [SideValue2 <397>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_397.html)
