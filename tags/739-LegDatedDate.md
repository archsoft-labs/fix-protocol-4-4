# FIX 4.4 : LegDatedDate <739> field

**Type:** [LocalMktDate](https://www.onixs.biz/fix-dictionary/4.4/index.html#LocalMktDate)

## Description

The effective date of a new securities issue determined by its underwriters. Often but not always the same as the [IssueDate <225>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_225.html) and the [InterestAccrualDate <874>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_874.html)
