# FIX 4.4 : MarginRatio <898> field

**Type:** [Percentage](https://www.onixs.biz/fix-dictionary/4.4/index.html#Percentage)

## Description

The fraction of the cash consideration that must be collateralized, expressed as a percent. A [MarginRatio <898>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_898.html) of 102% indicates that the value of the collateral (after deducting for "haircut") must exceed the cash consideration by 2%.
