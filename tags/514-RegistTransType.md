# FIX 4.4 : RegistTransType <514> field

**Type:** [char](https://www.onixs.biz/fix-dictionary/4.4/index.html#char)

## Description

Identifies [Registration Instructions <o>](https://www.onixs.biz/fix-dictionary/4.4/msgType_o_111.html) transaction type

Valid values:

0 = New

1 = Replace

2 = Cancel
