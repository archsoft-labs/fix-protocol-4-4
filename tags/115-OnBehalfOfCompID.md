# FIX 4.4 : OnBehalfOfCompID <115> field

**Type:** [String](https://www.onixs.biz/fix-dictionary/4.4/index.html#String)

## Description

Assigned value used to identify firm originating message if the message was delivered by a third party i.e. the third party firm identifier would be delivered in the [SenderCompID <49>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_49.html) field and the firm originating the message in this field.
