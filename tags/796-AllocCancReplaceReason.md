# FIX 4.4 : AllocCancReplaceReason <796> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Reason for cancelling or replacing an [Allocation Instruction <J>](https://www.onixs.biz/fix-dictionary/4.4/msgType_J_74.html) or [Allocation Report <AS>](https://www.onixs.biz/fix-dictionary/4.4/msgType_AS_6583.html) message

Valid values:

1 = Original details incomplete/incorrect

2 = Change in underlying order details

99 = Other

- [Allocation Instruction <J>](https://www.onixs.biz/fix-dictionary/4.4/msgType_J_74.html)
