# FIX 4.4 : CollAsgnRejectReason <906> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

[Collateral Assignment <AY>](https://www.onixs.biz/fix-dictionary/4.4/msgType_AY_6589.html) Reject Reason

Valid values:

0 = Unknown deal (order / trade)

1 = Unknown or invalid instrument

2 = Unauthorized transaction

3 = Insufficient collateral

4 = Invalid type of collateral

5 = Excessive substitution

99 = Other

- [Collateral Response <AZ>](https://www.onixs.biz/fix-dictionary/4.4/msgType_AZ_6590.html)
