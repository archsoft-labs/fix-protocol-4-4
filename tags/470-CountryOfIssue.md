# FIX 4.4 : CountryOfIssue <470> field

**Type:** [Country](https://www.onixs.biz/fix-dictionary/4.4/index.html#Country)

## Description

ISO [Country <421>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_421.html) code of instrument issue (e.g. the country portion typically used in ISIN). Can be used in conjunction with non-ISIN [SecurityID <48>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_48.html) (e.g. CUSIP for Municipal Bonds without ISIN) to provide uniqueness.
