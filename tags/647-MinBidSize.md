# FIX 4.4 : MinBidSize <647> field

**Type:** [Qty](https://www.onixs.biz/fix-dictionary/4.4/index.html#Qty)

## Description

Used to indicate a minimum quantity for a bid. If this field is used the [BidSize <134>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_134.html) field is interpreted as the maximum bid size
