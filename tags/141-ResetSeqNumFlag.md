# FIX 4.4 : ResetSeqNumFlag <141> field

**Type:** [Boolean](https://www.onixs.biz/fix-dictionary/4.4/index.html#Boolean)

## Description

Indicates that the both sides of the FIX session should reset sequence numbers.

Valid values:

Y = Yes, reset sequence numbers

N = No
