# FIX 4.4 : SecondaryClOrdID <526> field

**Type:** [String](https://www.onixs.biz/fix-dictionary/4.4/index.html#String)

## Description

Assigned by the party which originates the order. Can be used to provide the [ClOrdID <11>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_11.html) used by an exchange or executing system.
