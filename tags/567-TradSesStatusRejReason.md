# FIX 4.4 : TradSesStatusRejReason <567> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Indicates the reason a [Trading Session Status Request <g>](https://www.onixs.biz/fix-dictionary/4.4/msgType_g_103.html) was rejected.

Valid values:

1 = Unknown or invalid [TradingSessionID <336>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_336.html)

99 = Other
