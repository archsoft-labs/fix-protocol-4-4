# FIX 4.4 : BasisFeatureDate <259> field

**Type:** [LocalMktDate](https://www.onixs.biz/fix-dictionary/4.4/index.html#LocalMktDate)

## Description

[BasisFeatureDate <259>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_259.html) allows requesting firms within fixed income the ability to request an alternative yield-to-worst, -maturity, -extended or other call. This flows through the confirm process.

(Note tag # was reserved in FIX 4.1, added in FIX 4.3)

(prior to FIX 4.4 field was of type [UTCDate](https://www.onixs.biz/fix-dictionary/4.4/index.html#UTCDateOnly))
