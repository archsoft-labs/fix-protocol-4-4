# FIX 4.4 : RefAllocID <72> field

**Type:** [String](https://www.onixs.biz/fix-dictionary/4.4/index.html#String)

## Description

Reference identifier to be used with [AllocTransType <71>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_71.html) = 'Replace' or 'Cancel'.

(Prior to FIX 4.1 this field was of type int)
