# FIX 4.4 : ReportToExch <113> field

**Type:** [Boolean](https://www.onixs.biz/fix-dictionary/4.4/index.html#Boolean)

## Description

Identifies party of trade responsible for exchange reporting.

Valid values:

Y = Indicates that party receiving message must report trade

N = Indicates that party sending message will report trade
