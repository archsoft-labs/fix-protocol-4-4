# FIX 4.4 : IOINaturalFlag <130> field

**Type:** [Boolean](https://www.onixs.biz/fix-dictionary/4.4/index.html#Boolean)

## Description

Indicates that [IOI <6>](https://www.onixs.biz/fix-dictionary/4.4/msgType_6_6.html) is the result of an existing agency order or a facilitation position resulting from an agency order, not from principal trading or order solicitation activity.

Valid values:

Y = Natural

N = Not natural

- [IOI <6>](https://www.onixs.biz/fix-dictionary/4.4/msgType_6_6.html)
