# FIX 4.4 : PegOffsetValue <211> field

**Type:** [float](https://www.onixs.biz/fix-dictionary/4.4/index.html#float)

## Description

Amount (signed) added to the peg for a pegged order in the context of the [PegOffsetType <836>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_836.html)

(Prior to FIX 4.4 this field was of type [PriceOffset](https://www.onixs.biz/fix-dictionary/4.4/index.html#PriceOffset))
