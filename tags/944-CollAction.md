# FIX 4.4 : CollAction <944> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Action proposed for an [<UnderlyingInstrument>](https://www.onixs.biz/fix-dictionary/4.4/compBlock_UnderlyingInstrument.html) instance.

Valid values:

0 = Retain

1 = Add

2 = Remove
