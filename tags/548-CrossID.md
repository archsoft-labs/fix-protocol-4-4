# FIX 4.4 : CrossID <548> field

**Type:** [String](https://www.onixs.biz/fix-dictionary/4.4/index.html#String)

## Description

Identifier for a cross order. Must be unique during a given trading day. Recommend that firms use the order date as part of the [CrossID <548>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_548.html) for Good Till Cancel (GT) orders.
