# FIX 4.4 : ParticipationRate <849> field

**Type:** [Percentage](https://www.onixs.biz/fix-dictionary/4.4/index.html#Percentage)

## Description

For a [TargetStrategy <847>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_847.html)="Participate" order specifies the target particpation rate. For other order types this is a volume limit (i.e. do not be more than this percent of the market volume)
