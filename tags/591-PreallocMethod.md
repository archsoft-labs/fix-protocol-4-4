# FIX 4.4 : PreallocMethod <591> field

**Type:** [char](https://www.onixs.biz/fix-dictionary/4.4/index.html#char)

## Description

Indicates the method of preallocation.

Valid values:

0 = Pro-rata

1 = Do not pro-rata = discuss first
