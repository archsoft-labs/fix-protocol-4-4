# FIX 4.4 : FundRenewWaiv <497> field

**Type:** [char](https://www.onixs.biz/fix-dictionary/4.4/index.html#char)

## Description

A one character code identifying whether the Fund based renewal commission is to be waived.

Valid values are:

Y = Yes

N = No
