# FIX 4.4 : MassStatusReqType <585> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

[Mass Status Request <AF>](https://www.onixs.biz/fix-dictionary/4.4/msgType_AF_6570.html) Type

Valid values:

1 = Status for orders for a security

2 = Status for orders for an Underlying security

3 = Status for orders for a [Product <460>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_460.html)

4 = Status for orders for a [CFICode <461>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_461.html)

5 = Status for orders for a [SecurityType <167>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_167.html)

6 = Status for orders for a trading session

7 = Status for all orders

8 = Status for orders for a [PartyID <448>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_448.html)
