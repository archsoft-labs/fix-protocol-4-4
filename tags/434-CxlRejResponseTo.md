# FIX 4.4 : CxlRejResponseTo <434> field

**Type:** [char](https://www.onixs.biz/fix-dictionary/4.4/index.html#char)

## Description

Identifies the type of request that a [Cancel Reject <9>](https://www.onixs.biz/fix-dictionary/4.4/msgType_9_9.html) is in response to.

Valid values:

1 = [Order Cancel Request <F>](https://www.onixs.biz/fix-dictionary/4.4/msgType_F_70.html)

2 = [Order Cancel/Replace Request <G>](https://www.onixs.biz/fix-dictionary/4.4/msgType_G_71.html)

## Used In

- [Order Cancel Reject <9>](https://www.onixs.biz/fix-dictionary/4.4/msgType_9_9.html)
