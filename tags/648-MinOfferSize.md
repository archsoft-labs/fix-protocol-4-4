# FIX 4.4 : MinOfferSize <648> field

**Type:** [Qty](https://www.onixs.biz/fix-dictionary/4.4/index.html#Qty)

## Description

Used to indicate a minimum quantity for an offer. If this field is used the [OfferSize <135>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_135.html) field is interpreted as the maximum offer size.
