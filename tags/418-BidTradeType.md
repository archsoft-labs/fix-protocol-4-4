# FIX 4.4 : BidTradeType <418> field

**Type:** [char](https://www.onixs.biz/fix-dictionary/4.4/index.html#char)

## Description

Code to represent the type of trade.

Valid values:

R = Risk Trade

G = VWAP Guarantee

A = Agency

J = Guaranteed Close

(Prior to FIX 4.4 this field was named "TradeType")
