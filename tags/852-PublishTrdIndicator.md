# FIX 4.4 : PublishTrdIndicator <852> field

**Type:** [Boolean](https://www.onixs.biz/fix-dictionary/4.4/index.html#Boolean)

## Description

Indicates if a trade should be reported via a market reporting service.

Valid values:

Y = Report trade

N = Do not report trade
