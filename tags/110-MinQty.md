# FIX 4.4 : MinQty <110> field

**Type:** [Qty](https://www.onixs.biz/fix-dictionary/4.4/index.html#Qty)

## Description

Minimum quantity of an order to be executed.

(Prior to FIX 4.2 this field was of type int)
