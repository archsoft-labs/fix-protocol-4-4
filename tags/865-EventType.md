# FIX 4.4 : EventType <865> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Code to represent the type of event

Valid values:

1 = [Put](https://www.onixs.biz/fix-dictionary/4.4/glossary.html#PutDate)

2 = [Call](https://www.onixs.biz/fix-dictionary/4.4/glossary.html#CallDate)

3 = Tender

4 = Sinking Fund Call

99 = Other
