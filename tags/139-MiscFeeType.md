# FIX 4.4 : MiscFeeType <139> field

**Type:** [char](https://www.onixs.biz/fix-dictionary/4.4/index.html#char)

## Description

Indicates type of miscellaneous fee.

Valid values:

1 = Regulatory (e.g. SEC)

2 = Tax

3 = Local Commission

4 = Exchange Fees

5 = Stamp

6 = Levy

7 = Other

8 = Markup

9 = Consumption Tax

10 = Per transaction

11 = Conversion

12 = Agent
