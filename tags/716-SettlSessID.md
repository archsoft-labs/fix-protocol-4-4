# FIX 4.4 : SettlSessID <716> field

**Type:** [String](https://www.onixs.biz/fix-dictionary/4.4/index.html#String)

## Description

Identifies a specific settlement session

Examples:

ITD = Intraday

RTH = Regular Trading Hours

ETH = Electronic Trading Hours
