# FIX 4.4 : EncodedHeadline <359> field

**Type:** [data](https://www.onixs.biz/fix-dictionary/4.4/index.html#data)

## Description

Encoded (non-ASCII characters) representation of the [Headline <148>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_148.html) field in the encoded format specified via the [MessageEncoding <347>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_347.html) field. If used, the ASCII (English) representation should also be specified in the [Headline <148>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_148.html) field.
