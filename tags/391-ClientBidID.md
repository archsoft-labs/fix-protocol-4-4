# FIX 4.4 : ClientBidID <391> field

**Type:** [String](https://www.onixs.biz/fix-dictionary/4.4/index.html#String)

## Description

Unique identifier for a [Bid Request <k>](https://www.onixs.biz/fix-dictionary/4.4/msgType_k_107.html) as assigned by institution. Uniqueness must be guaranteed within a single trading day.
