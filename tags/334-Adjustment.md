# FIX 4.4 : Adjustment <334> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Identifies the type of adjustment.

Valid values:

1 = Cancel

2 = Error

3 = Correction
