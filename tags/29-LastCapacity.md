# FIX 4.4 : LastCapacity <29> field

**Type:** [char](https://www.onixs.biz/fix-dictionary/4.4/index.html#char)

## Description

Broker capacity in order execution

Valid values:

1 = Agent

2 = Cross as agent

3 = Cross as principal

4 = Principal
