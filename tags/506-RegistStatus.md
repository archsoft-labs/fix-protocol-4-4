# FIX 4.4 : RegistStatus <506> field

**Type:** [char](https://www.onixs.biz/fix-dictionary/4.4/index.html#char)

## Description

Registration status as returned by the broker or (for CIV) the fund manager:

Valid values:

A = Accepted

R = Rejected

H = Held

N = Reminder - i.e. [Registration Instructions <o>](https://www.onixs.biz/fix-dictionary/4.4/msgType_o_111.html) are still outstanding
