# FIX 4.4 : DlvyInstType <787> field

**Type:** [char](https://www.onixs.biz/fix-dictionary/4.4/index.html#char)

## Description

Used to indicate whether a delivery instruction is used for securities or cash settlement.

Valid values:

S = securities

C = cash
