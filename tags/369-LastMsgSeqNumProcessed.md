# FIX 4.4 : LastMsgSeqNumProcessed <369> field

**Type:** [SeqNum](https://www.onixs.biz/fix-dictionary/4.4/index.html#SeqNum)

## Description

The last [MsgSeqNum <34>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_34.html) value received by the FIX engine and processed by downstream application, such as trading engine or order routing system. Can be specified on every message sent. Useful for detecting a backlog with a counterparty.
