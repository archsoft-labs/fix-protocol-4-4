# FIX 4.4 : EncodedSubject <357> field

**Type:** [data](https://www.onixs.biz/fix-dictionary/4.4/index.html#data)

## Description

Encoded (non-ASCII characters) representation of the [Subject <147>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_147.html) field in the encoded format specified via the [MessageEncoding <347>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_347.html) field. If used, the ASCII (English) representation should also be specified in the [Subject <147>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_147.html) field.

- [Email <C>](https://www.onixs.biz/fix-dictionary/4.4/msgType_C_67.html)
