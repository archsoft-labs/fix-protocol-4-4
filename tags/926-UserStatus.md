# FIX 4.4 : UserStatus <926> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Indicates the status of a user

Valid values:

1 = Logged In

2 = Not Logged In

3 = User Not Recognised

4 = [Password <554>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_554.html) Incorrect

5 = [Password <554>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_554.html) Changed

6 = Other
