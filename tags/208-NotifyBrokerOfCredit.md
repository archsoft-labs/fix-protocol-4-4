# FIX 4.4 : NotifyBrokerOfCredit <208> field

**Type:** [Boolean](https://www.onixs.biz/fix-dictionary/4.4/index.html#Boolean)

## Description

Indicates whether or not details should be communicated to [BrokerOfCredit <92>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_92.html) (i.e. step-in broker).

Valid values:

Y = Details should be communicated

N = Details should not be communicated
