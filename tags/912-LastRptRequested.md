# FIX 4.4 : LastRptRequested <912> field

**Type:** [Boolean](https://www.onixs.biz/fix-dictionary/4.4/index.html#Boolean)

## Description

Indicates whether this message is that last report message in response to a request, such as [Order Mass Status Request <AF>](https://www.onixs.biz/fix-dictionary/4.4/msgType_AF_6570.html).

Valid values:

Y = Last message

N = Not last message
