# FIX 4.4 : QuantityType <465> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

*** DEPRECATED FIELD — See [QtyType <854>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_854.html) ***

Designates the type of quantities (e.g. [OrderQty <38>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_38.html)) specified. Used for MBS and TIPS Fixed Income security types.

Valid values:

1 = SHARES

2 = BONDS

3 = CURRENTFACE

4 = ORIGINALFACE

5 = CURRENCY

6 = CONTRACTS

7 = OTHER

8 = [PAR](https://www.onixs.biz/fix-dictionary/4.4/glossary.html#Par)
