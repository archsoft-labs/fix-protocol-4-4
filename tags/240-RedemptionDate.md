# FIX 4.4 : RedemptionDate <240> field

**Type:** [LocalMktDate](https://www.onixs.biz/fix-dictionary/4.4/index.html#LocalMktDate)

## Description

*** DEPRECATED FIELD - See [Appendix 6-E: 3.Deprecated Instrument-affiliated "RedemptionDate" Fields: RedemptionDate (240), UnderlyingRedemptionDate (247), and LegRedemptionDate (254) [deprecated in FIX 4.4]](https://www.onixs.biz/fix-dictionary/4.4/app_6_e.html#3) ***

Return of investor's principal in a security. Bond redemption can occur before maturity date.

(Note tag # was reserved in FIX 4.1, added in FIX 4.3)

(prior to FIX 4.4 field was of type [UTCDate](https://www.onixs.biz/fix-dictionary/4.4/index.html#UTCDateOnly))
