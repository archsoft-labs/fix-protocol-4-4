# FIX 4.4 : TickDirection <274> field

**Type:** [char](https://www.onixs.biz/fix-dictionary/4.4/index.html#char)

## Description

Direction of the "tick".

Valid values:

0 = Plus Tick

1 = Zero-Plus Tick

2 = Minus Tick

3 = Zero-Minus Tick
