# FIX 4.4 : AllocLinkType <197> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Identifies the type of Allocation linkage when [AllocLinkID <196>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_196.html) is used.

Valid values:

0 = F/X Netting

1 = F/X Swap
