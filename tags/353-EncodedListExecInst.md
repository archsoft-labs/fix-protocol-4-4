# FIX 4.4 : EncodedListExecInst <353> field

**Type:** [data](https://www.onixs.biz/fix-dictionary/4.4/index.html#data)

## Description

Encoded (non-ASCII characters) representation of the [ListExecInst <69>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_69.html) field in the encoded format specified via the [MessageEncoding <347>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_347.html) field. If used, the ASCII (English) representation should also be specified in the [ListExecInst <69>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_69.html) field.

## Used In

- [New Order List <E>](https://www.onixs.biz/fix-dictionary/4.4/msgType_E_69.html)
