# FIX 4.4 : MiscFeeBasis <891> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Defines the unit for a miscellaneous fee.

Valid values:

0 = Absolute

1 = Per unit

2 = Percentage
