# FIX 4.4 : StatusValue <928> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Indicates the status of a network connection

Valid values:

1 = Connected

2 = Not connected - down expected up

3 = Not connected - down expected down

4 = In Process
