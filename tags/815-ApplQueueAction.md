# FIX 4.4 : ApplQueueAction <815> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Action to take to resolve an application message queue (backlog).

Valid values:

0 = No action taken

1 = Queue flushed

2 = Overlay last

3 = End session
