# FIX 4.4 : OrigClOrdID <41> field

**Type:** [String](https://www.onixs.biz/fix-dictionary/4.4/index.html#String)

## Description

[ClOrdID <11>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_11.html) of the previous order (NOT the initial order of the day) as assigned by the institution, used to identify the previous order in cancel and cancel/replace requests.
