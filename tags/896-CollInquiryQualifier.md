# FIX 4.4 : CollInquiryQualifier <896> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Collateral inquiry qualifiers

Valid values:

0 = Trade Date

1 = GC Instrument

2 = CollateralInstrument

3 = Substitution Eligible

4 = Not Assigned

5 = Partially Assigned

6 = Fully Assigned

7 = Outstanding Trades (Today < end date)
