# FIX 4.4 : Currency <15> field

**Type:** [Currency](https://www.onixs.biz/fix-dictionary/4.4/index.html#Currency)

## Description

Identifies currency used for price. Absence of this field is interpreted as the default for the security. It is recommended that systems provide the currency value whenever possible. See [Appendix 6-A: Valid Currency Codes](https://www.onixs.biz/fix-dictionary/4.4/app_6_a.html) for information on obtaining valid values.
