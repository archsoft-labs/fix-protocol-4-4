# FIX 4.4 : MatchStatus <573> field

**Type:** [char](https://www.onixs.biz/fix-dictionary/4.4/index.html#char)

## Description

The status of this trade with respect to matching or comparison.

Valid values:

0 = compared, matched or affirmed

1 = uncompared, unmatched, or unaffirmed

2 = advisory or alert
