# FIX 4.4 : SymbolSfx <65> field

**Type:** [String](https://www.onixs.biz/fix-dictionary/4.4/index.html#String)

## Description

Additional information about the security (e.g. preferred, warrants, etc.). Note also see [SecurityType <167>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_167.html).

Valid values:

As defined in the NYSE Stock and bond Symbol Directory and in the AMEX Fitch Directory

Fixed Income use:

WI = "When Issued" for a security to be reissued under an old CUSIP or ISIN

CD = a EUCP with lump-sum interest rather than discount price
