# FIX 4.4 : UserRequestType <924> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Indicates the action required by a [User Request <BE>](https://www.onixs.biz/fix-dictionary/4.4/msgType_BE_6669.html) Message

Valid values:

1 = LogOnUser

2 = LogOffUser

3 = ChangePasswordForUser

4 = Request Individual User Status
