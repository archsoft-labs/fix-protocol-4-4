# FIX 4.4 : SettlDeliveryType <172> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Identifies type of settlement

0 = "Versus. Payment": Deliver (if Sell) or Receive (if Buy) vs. (Against) Payment

1 = "Free": Deliver (if Sell) or Receive (if Buy) Free

2 = Tri-Party

3 = Hold In Custody
