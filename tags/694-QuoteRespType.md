# FIX 4.4 : QuoteRespType <694> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Identifies the type of [Quote Response <AJ>](https://www.onixs.biz/fix-dictionary/4.4/msgType_AJ_6574.html).

Valid values:

1 = Hit/Lift

2 = Counter

3 = Expired

4 = Cover

5 = Done Away

6 = Pass
