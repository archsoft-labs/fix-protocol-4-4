# FIX 4.4 : CorporateAction <292> field

**Type:** [MultipleValueString](https://www.onixs.biz/fix-dictionary/4.4/index.html#MultipleValueString)

## Description

Identifies the type of Corporate Action.

Valid values:

A = Ex-Dividend

B = Ex-Distribution

C = Ex-Rights

D = New

E = Ex-Interest
