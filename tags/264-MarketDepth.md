# FIX 4.4 : MarketDepth <264> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Depth of market for Book Snapshot

Valid values:

0 = Full Book

1 = Top of Book

N>1 = Report best N price tiers of data
