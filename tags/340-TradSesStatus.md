# FIX 4.4 : TradSesStatus <340> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

State of the trading session.

Valid values:

0 = Unknown

1 = Halted

2 = Open

3 = Closed

4 = Pre-Open

5 = Pre-Close

6 = Request Rejected
