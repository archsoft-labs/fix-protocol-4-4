# FIX 4.4 : CustomerOrFirm <204> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

No longer used as of FIX 4.3. Included here for reference to prior versions.

*** REPLACED FIELD - See [Appendix 6-F: 6.Replaced Field: CustomerOrFirm (tag 204) with OrderCapacity (tag 528) [Replaced in FIX 4.3]](https://www.onixs.biz/fix-dictionary/4.4/app_6_f.html#6) ***

Used for options when delivering the order to an execution system/exchange to specify if the order is for a customer or the firm placing the order itself.

~~Valid values:~~

~~0 = Customer~~

~~1 = Firm~~
