# FIX 4.4 : CollInquiryStatus <945> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Status of [Collateral Inquiry <BB>](https://www.onixs.biz/fix-dictionary/4.4/msgType_BB_6666.html)

Valid values:

0 = Accepted

1 = Accepted with Warnings

2 = Completed

3 = Completed with Warnings

4 = Rejected
