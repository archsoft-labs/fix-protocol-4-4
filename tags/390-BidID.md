# FIX 4.4 : BidID <390> field

**Type:** [String](https://www.onixs.biz/fix-dictionary/4.4/index.html#String)

## Description

Unique identifier for [Bid Response <l>](https://www.onixs.biz/fix-dictionary/4.4/msgType_l_108.html) as assigned by sell-side (broker, exchange, ECN). Uniqueness must be guaranteed within a single trading day.
