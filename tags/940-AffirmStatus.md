# FIX 4.4 : AffirmStatus <940> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Identifies the status of the ConfirmationAck.

Valid values:

1 = Received

2 = Confirm rejected, i.e. not affirmed

3 = Affirmed
