# FIX 4.4 : TradeReportType <856> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Type of Trade Report

Valid values:

0 = Submit

1 = Alleged

2 = Accept

3 = Decline

4 = Addendum

5 = No/Was

6 = Trade Report Cancel

7 = Locked In Trade Break
