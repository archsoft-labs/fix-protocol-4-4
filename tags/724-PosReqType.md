# FIX 4.4 : PosReqType <724> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Unique identifier for the position maintenance request as assigned by the submitter

Valid values:

0 = Positions

1 = Trades

2 = Exercises

3 = Assignments
