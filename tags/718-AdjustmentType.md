# FIX 4.4 : AdjustmentType <718> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Type of adjustment to be applied, used for PCS & PAJ

Valid values:

0 = Process request as Margin Disposition

1 = Delta_plus

2 = Delta_minus

3 = Final
