# FIX 4.4 : CollAsgnReason <895> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Reason for [Collateral Assignment <AY>](https://www.onixs.biz/fix-dictionary/4.4/msgType_AY_6589.html)

Valid values:

0 = Initial

1 = Scheduled

2 = Time Warning

3 = Margin Deficiency

4 = Margin Excess

5 = Forward Collateral Demand

6 = Event of default

7 = Adverse tax event
