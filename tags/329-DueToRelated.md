# FIX 4.4 : DueToRelated <329> field

**Type:** [Boolean](https://www.onixs.biz/fix-dictionary/4.4/index.html#Boolean)

## Description

Indicates whether or not the halt was due to the Related Security being halted.

Valid values:

Y = Halt was due to related security being halted

N = Halt was not related to a halt of the related security
