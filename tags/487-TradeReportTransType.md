# FIX 4.4 : TradeReportTransType <487> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Identifies Trade Report message transaction type

Valid values:

0 = New

1 = Cancel

2 = Replace

3 = Release

4 = Reverse

(Prior to FIX 4.4 this field was of type char)
