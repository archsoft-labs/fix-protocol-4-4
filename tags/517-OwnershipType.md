# FIX 4.4 : OwnershipType <517> field

**Type:** [char](https://www.onixs.biz/fix-dictionary/4.4/index.html#char)

## Description

The relationship between Registration parties.

Valid values:

2 = Joint Trustees

J = Joint Investors

T = Tenants in Common
