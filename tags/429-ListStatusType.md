# FIX 4.4 : ListStatusType <429> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Code to represent the status type.

Valid values:

1 = Ack

2 = Response

3 = Timed

4 = ExecStarted

5 = AllDone

6 = Alert
