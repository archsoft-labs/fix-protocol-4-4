# FIX 4.4 : LegPool <740> field

**Type:** [String](https://www.onixs.biz/fix-dictionary/4.4/index.html#String)

## Description

For Fixed Income, identifies MBS / ABS pool for a specific leg of a multi-leg instrument.

See [Pool <691>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_691.html) for description and valid values.
