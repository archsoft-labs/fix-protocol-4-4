# FIX 4.4 : RoutingType <216> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Indicates the type of [RoutingID <217>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_217.html) specified.

Valid values:

1 = Target Firm

2 = Target List

3 = Block Firm

4 = Block List
