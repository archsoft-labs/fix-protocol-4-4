# FIX 4.4 : AllocHandlInst <209> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Indicates how the receiver (i.e. third party) of Allocation message should handle/process the account details.

Valid values:

1 = Match

2 = Forward

3 = Forward and Match
