# FIX 4.4 : SecondaryExecID <527> field

**Type:** [String](https://www.onixs.biz/fix-dictionary/4.4/index.html#String)

## Description

Assigned by the party which accepts the order. Can be used to provide the [ExecID <17>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_17.html) used by an exchange or executing system.
