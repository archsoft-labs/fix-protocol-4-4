# FIX 4.4 : IOIQualifier <104> field

**Type:** [char](https://www.onixs.biz/fix-dictionary/4.4/index.html#char)

## Description

Code to qualify IOI use.

Valid values:

A = All or none

B = [Market On Close (MOC)](https://www.onixs.biz/fix-dictionary/4.4/glossary.html#MarketOnClose) (held to close)

C = [At the close](https://www.onixs.biz/fix-dictionary/4.4/glossary.html#AtTheClose) (around/not held to close)

D = VWAP (Volume Weighted Avg Price)

I = In touch with

L = Limit

M = More behind

O = At the open

P = Taking a position

Q = At the Market (previously called Current Quote)

R = Ready to trade

S = Portfolio shown

T = Through the day

V = Versus

W = Indication - Working away

X = Crossing opportunity

Y = At the Midpoint

Z = Pre-open
