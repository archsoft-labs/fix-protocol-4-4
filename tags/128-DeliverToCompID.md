# FIX 4.4 : DeliverToCompID <128> field

**Type:** [String](https://www.onixs.biz/fix-dictionary/4.4/index.html#String)

## Description

Assigned value used to identify the firm targeted to receive the message if the message is delivered by a third party i.e. the third party firm identifier would be delivered in the [TargetCompID <56>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_56.html) field and the ultimate receiver firm ID in this field.
