# FIX 4.4 : SecondaryOrderID <198> field

**Type:** [String](https://www.onixs.biz/fix-dictionary/4.4/index.html#String)

## Description

Assigned by the party which accepts the order. Can be used to provide the [OrderID <37>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_37.html) used by an exchange or executing system.
