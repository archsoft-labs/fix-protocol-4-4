# FIX 4.4 : TestMessageIndicator <464> field

**Type:** [Boolean](https://www.onixs.biz/fix-dictionary/4.4/index.html#Boolean)

## Description

Indicates whether or not this FIX Session is a "test" vs. "production" connection. Useful for preventing "accidents".

Valid values:

Y = True (Test)

N = False (Production)
