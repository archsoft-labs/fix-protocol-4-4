# FIX 4.4 : TradeOriginationDate <229> field

**Type:** [LocalMktDate](https://www.onixs.biz/fix-dictionary/4.4/index.html#LocalMktDate)

## Description

Used with Fixed Income for Muncipal New Issue Market. Agreement in principal between counter-parties prior to actual trade date.

(Note tag # was reserved in FIX 4.1, added in FIX 4.3)

(prior to FIX 4.4 field was of type UTCDate)
