# FIX 4.4 : UnderlyingDirtyPrice <882> field

**Type:** [Price](https://www.onixs.biz/fix-dictionary/4.4/index.html#Price)

## Description

Price (percent-of-par or per unit) of the underlying security or basket. "Dirty" means it includes accrued interest
