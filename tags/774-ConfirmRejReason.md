# FIX 4.4 : ConfirmRejReason <774> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Identifies the reason for rejecting a [Confirmation <AK>](https://www.onixs.biz/fix-dictionary/4.4/msgType_AK_6575.html).

Valid values:

1 = Mismatched account

2 = Missing settlement instructions

99 = Other

- [Confirmation Ack <AU>](https://www.onixs.biz/fix-dictionary/4.4/msgType_AU_6585.html)
