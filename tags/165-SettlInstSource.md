# FIX 4.4 : SettlInstSource <165> field

**Type:** [char](https://www.onixs.biz/fix-dictionary/4.4/index.html#char)

## Description

Indicates source of [Settlement Instructions <T>](https://www.onixs.biz/fix-dictionary/4.4/msgType_T_84.html)

Valid values:

1 = Broker's Instructions

2 = Institution's Instructions

3 = Investor (e.g. CIV use)
