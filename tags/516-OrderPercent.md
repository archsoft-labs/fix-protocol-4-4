# FIX 4.4 : OrderPercent <516> field

**Type:** [Percentage](https://www.onixs.biz/fix-dictionary/4.4/index.html#Percentage)

## Description

For CIV specifies the approximate order quantity desired. For a CIV Sale it specifies percentage of investor's total holding to be sold. For a CIV switch/exchange it specifies percentage of investor's cash realised from sales to be re-invested. The executing broker, intermediary or fund manager is responsible for converting and calculating [OrderQty <38>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_38.html) in shares/units for subsequent messages.
