# FIX 4.4 : TradedFlatSwitch <258> field

**Type:** [Boolean](https://www.onixs.biz/fix-dictionary/4.4/index.html#Boolean)

## Description

Driver and part of trade in the event that the Security Master file was wrong at the point of entry

Valid values:

Y = Traded Flat

N = Not Traded Flat
