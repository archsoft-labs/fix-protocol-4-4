# FIX 4.4 : HaltReason <327> field

**Type:** [char](https://www.onixs.biz/fix-dictionary/4.4/index.html#char)

## Description

Denotes the reason for the Opening Delay or Trading Halt.

Valid values:

I = Order Imbalance

X = Equipment Changeover

P = [News <B>](https://www.onixs.biz/fix-dictionary/4.4/msgType_B_66.html) Pending

D = [News <B>](https://www.onixs.biz/fix-dictionary/4.4/msgType_B_66.html) Dissemination

E = Order Influx

M = Additional Information
