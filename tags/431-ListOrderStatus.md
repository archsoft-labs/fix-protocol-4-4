# FIX 4.4 : ListOrderStatus <431> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Code to represent the status of a list order.

Valid values:

1 = InBiddingProcess

2 = ReceivedForExecution

3 = Executing

4 = Canceling

5 = Alert

6 = All Done

7 = Reject
