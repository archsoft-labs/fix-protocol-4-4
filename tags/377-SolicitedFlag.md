# FIX 4.4 : SolicitedFlag <377> field

**Type:** [Boolean](https://www.onixs.biz/fix-dictionary/4.4/index.html#Boolean)

## Description

Indicates whether or not the order was solicited.

Valid values:

Y = Was solcitied

N = Was not solicited
