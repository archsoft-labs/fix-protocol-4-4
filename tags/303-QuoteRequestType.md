# FIX 4.4 : QuoteRequestType <303> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Indicates the type of [Quote Request <R>](https://www.onixs.biz/fix-dictionary/4.4/msgType_R_82.html) being generated

Valid values:

1 = Manual

2 = Automatic
