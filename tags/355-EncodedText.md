# FIX 4.4 : EncodedText <355> field

**Type:** [data](https://www.onixs.biz/fix-dictionary/4.4/index.html#data)

## Description

Encoded (non-ASCII characters) representation of the [Text <58>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_58.html) field in the encoded format specified via the [MessageEncoding <347>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_347.html) field. If used, the ASCII (English) representation should also be specified in the [Text <58>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_58.html) field.
