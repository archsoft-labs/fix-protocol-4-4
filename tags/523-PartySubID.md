# FIX 4.4 : PartySubID <523> field

**Type:** [String](https://www.onixs.biz/fix-dictionary/4.4/index.html#String)

## Description

Sub-identifier (e.g. Clearing Account for [PartyRole <452>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_452.html)=Clearing Firm, Locate ID # for [PartyRole <452>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_452.html)=Locate/Lending Firm, etc). Not required when using [PartyID <448>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_448.html), [PartyIDSource <447>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_447.html), and [PartyRole <452>](https://www.onixs.biz/fix-dictionary/4.4/tagNum_452.html).
