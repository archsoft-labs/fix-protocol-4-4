# FIX 4.4 : SettlInstTransType <163> field

**Type:** [char](https://www.onixs.biz/fix-dictionary/4.4/index.html#char)

## Description

[Settlement Instructions <T>](https://www.onixs.biz/fix-dictionary/4.4/msgType_T_84.html) message transaction type

Valid values:

N = New

C = Cancel

R = Replace

T = Restate (used where the Settlement Instruction is being used to communicate standing instructions which have not been changed or added to)
