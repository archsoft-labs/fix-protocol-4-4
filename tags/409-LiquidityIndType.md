# FIX 4.4 : LiquidityIndType <409> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Code to identify the type of liquidity indicator.

Valid values:

1 = 5day moving average

2 = 20 day moving average

3 = Normal Market Size

4 = Other
