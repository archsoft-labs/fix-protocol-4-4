# FIX 4.4 : ProgPeriodInterval <415> field

**Type:** [int](https://www.onixs.biz/fix-dictionary/4.4/index.html#int)

## Description

Time in minutes between each [ListStatus <N>](https://www.onixs.biz/fix-dictionary/4.4/msgType_N_78.html) report sent by SellSide. Zero means don't send status.
