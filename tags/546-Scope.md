# FIX 4.4 : Scope <546> field

**Type:** [MultipleValueString](https://www.onixs.biz/fix-dictionary/4.4/index.html#MultipleValueString)

## Description

Defines the scope of a data element.

Valid values:

1 = Local (Exchange, ECN, ATS)

2 = National

3 = Global
