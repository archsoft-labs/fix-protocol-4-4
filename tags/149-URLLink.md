# FIX 4.4 : URLLink <149> field

**Type:** [String](https://www.onixs.biz/fix-dictionary/4.4/index.html#String)

## Description

A URI (Uniform Resource Identifier) or URL (Uniform Resource Locator) link to additional information (i.e. https://en.wikipedia.org/wiki/URL)
